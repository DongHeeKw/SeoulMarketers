# 23. Low-cost Hosting, Deployment, Monitoring

## 환경
- 개발 PC: 코드 학습, local unit tests, Playwright.
- Ubuntu PC: 공공데이터 ETL/스냅샷 생성, 초기 Postgres, 예약 작업.
- Vercel: 초기 비상업적 preview/SSR 또는 정적 사이트 배포, 제공업체 플랜 제한 준수.
- 유료 전환 시 상업용 배포 이용약관/사업자·개인정보·세금 검토.

## 장애를 줄이는 핵심 설계
공개 초기 페이지는 매 요청마다 가정용 PC 응답을 기다리지 않는다. 배치로 생성한 갱신된 공개 데이터 스냅샷을 CDN에서 제공한다. 사용자가 기대하는 실시간 기능이 필요해지면 별도의 인증·요청제한·헬스체크된 API를 검토한다.

## 도메인
Vercel 무료 하위 도메인으로 MVP를 검증. 독립 도메인은 갱신비용이 든다. Cloudflare DNS는 무료 티어 사용 가능; DNS 자체 구축은 불필요. 서브도메인 확장은 단일 도메인 갱신료로 가능. 등록가와 갱신가 구별.

## 설정 및 백업
`.env.example`에는 이름만, 실제 키는 Secret Store에. Postgres는 인터넷에 직접 노출 금지, 마이그레이션 백업, 주기 복구 리허설. 로그와 Metrics는 데이터 수집시점/실패건수/조회 오류/응답지연 중심.

## SEO
서버 렌더링 가능한 진짜 설명 콘텐츠, canonical/sitemap/robots, 빈 페이지 noindex, 원본 출처·갱신일. 얇은 복제 페이지 대량 생성 금지.

## 확장 기준
CPU/메모리/전력 실측 → 방문자/쿼리 측정 → 필요할 때만 분리 배포. 추측으로 마이크로서비스 만들지 않는다.
